2nd Runner-Up at National HackFest. A React, Node.js and Python LangGraph-based financial investigation platform featuring DAG cycle detection and sanctions screening, reducing investigations from 2–3 days to under 10 seconds.

[Live Demo](https://unshell-eight.vercel.app/) | [GitHub](https://github.com/nehalikareddy/unshell)
